## 3. Technical Challenges & Resolutions

- **Challenge**: `verify-system.ps1` failed because Airflow CLI emitted warning/log lines before JSON.
- **Resolution**: Added a JSON extraction helper before `ConvertFrom-Json` and unpaused `smoke_dag` before triggering it.

- **Challenge**: Repeated pipeline runs accumulated old rows in ClickHouse raw tables, allowing stale bad data to survive into gold models.
- **Resolution**: Added a full-refresh step that truncates all raw source tables before loading the latest Postgres staging data.

- **Challenge**: The custom quality gate kept failing on invalid latency because `int-1003` had `ended_at` earlier than `started_at`.
- **Resolution**: Corrected the seed data so `int-1003` has a positive 60 second latency, then reran the pipeline and confirmed `invalid_latency = 0`.

- **Challenge**: `smoke_dag` marked Langfuse as healthy even when the check failed.
- **Resolution**: Removed the broad exception fallback from the Langfuse health task so the DAG reports real connectivity failures.

- **Challenge**: dbt warned about an unused `bronze` model config.
- **Resolution**: Removed the unused config and verified `dbt build` now completes with no warnings.

- **Challenge**: ClickHouse rejected ordinary SigNoz log rows with `NULL` `trace_id` values because raw tables use non-nullable `String` columns.
- **Resolution**: Added ingestion sanitizers such as `clean_str`, `clean_int`, and `clean_float` in `dags/agentic_bi_pipeline.py`, then mapped nullable identifiers and text fields to safe defaults before ClickHouse insert.

- **Challenge**: ClickHouse insert failed when `raw.user_interactions.ended_at` was `NULL`, because the driver attempted timestamp conversion on `None`.
- **Resolution**: Updated the user interaction mapping so missing `ended_at` falls back to `started_at`, producing a valid zero-latency telemetry row instead of crashing the pipeline.
