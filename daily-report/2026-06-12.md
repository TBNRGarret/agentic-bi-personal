## 3. Technical Challenges & Resolutions

- **Challenge**: The Astro Airflow containers mount the project directory under `/usr/local/airflow/` as read-only, which caused dbt execution to fail with `PermissionError: [Errno 13] Permission denied: '/usr/local/airflow/include/dbt_project/target'`.
  - **Resolution**: Updated `dbt_project.yml` to specify output folders in the container's writable directory: `target-path: "/tmp/dbt_target"`, `log-path: "/tmp/dbt_logs"`, and `packages-install-path: "/tmp/dbt_packages"`.
- **Challenge**: Containers launched via Astro CLI could not talk to ClickHouse or DataHub because they were started on a distinct default Docker bridge.
  - **Resolution**: Developed [connect-networks.sh](file:///home/ubuntu/agentic-bi/scripts/connect-networks.sh) to attach all running Airflow containers to the external `dwh_network` and `datahub_network`.
- **Challenge**: Attempting to query ClickHouse in validation scripts using `docker exec` with standard interactive clients would hang or time out.
  - **Resolution**: Switched validation scripts to communicate with the ClickHouse HTTP API on port `18123` using standard HTTP calls or `clickhouse-connect`.
